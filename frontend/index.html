Plot Extraction & StatisticsDrone-based plot detection, editing & per-plot data

Drone Orthomosaic

Needs a cm-resolution drone orthomosaic (Pix4D/Agisoft/ODM output) — satellite imagery is too coarse to resolve individual plants or plots.

Automatic Plot Extraction

Vegetation mask: detects each planted/green area as its own plot — best when plots are visually greener than their surroundings. AI segmentation: uses a pretrained model to find visually distinct regions in general, better when plots are separated by bare dirt tracks instead of by canopy color. Saves to the current boundary if one is loaded.

Image Acquisition Requirements

For automatic plot extraction and plant counts to work, upload a nadir (straight-down) orthomosaic GeoTIFF stitched from a drone flight — not a single oblique photo. Typical settings: fly at a height giving 2–5cm/pixel ground resolution, 75%+ front overlap and 65%+ side overlap between photos, then stitch with Pix4D, DroneDeploy, Agisoft Metashape, or the free OpenDroneMap. Export the result as a GeoTIFF (.tif). A single non-georeferenced photo (e.g. a phone or gimbal shot) will not produce accurate plot boundaries or areas.

Manual Plot Tools

Splits the boundary into a regular, evenly-sized grid — use this for planned layouts before any imagery exists.
Turns on map editing for the current plots — drag a corner to reshape, draw a new polygon to add a plot, or use the trash tool to delete one. Changes save automatically.
